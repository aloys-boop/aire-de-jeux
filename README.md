# Aire de jeux

Jeux de route entre potes, sur un seul téléphone : le Bingo de l’autoroute, le Jeu des plaques, On s’en souviendra ?, Tu préfères, Devine le prix, Qui a le plus progressé ?, Qui a été le plus recherché ?, Avant ou après ?, La cote de Claude, Le mensonge de Claude et Qui de nous ?.

Appli : https://aloys-boop.github.io/aire-de-jeux/

Sur iPhone : ouvrir le lien dans Safari, puis Partager et « Sur l’écran d’accueil ». Une fois ouverte une première fois, l’appli fonctionne sans réseau.
